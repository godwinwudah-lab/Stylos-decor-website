# Stylo's Decor and Paintings — Website

A clean, elegant single-page website for Stylo's Decor and Paintings.

## What's included

- **index.html** — Complete website (HTML + Tailwind CSS + light JavaScript)
- Responsive design (works on phone, tablet, and desktop)
- Smooth scrolling navigation
- Portfolio gallery section
- Contact form (demo — needs connecting to a form service)

## How to view it right now

1. Open the `index.html` file in any modern browser (Chrome, Firefox, Safari, Edge).
2. That's it — no installation required.

## How to put it online (free options)

### Option 1: Netlify (easiest)
1. Go to [netlify.com](https://www.netlify.com) and sign up (free).
2. Drag and drop the entire `stylos-website` folder onto the Netlify dashboard.
3. Your site will be live in seconds with a free URL like `stylos-decor.netlify.app`.
4. You can later connect your own domain name.

### Option 2: Vercel
1. Go to [vercel.com](https://vercel.com) and sign up.
2. Import the folder or drag & drop.
3. Deploy.

### Option 3: GitHub Pages
1. Create a free GitHub account.
2. Create a new repository.
3. Upload the files.
4. Enable GitHub Pages in the repository settings.

## Customizing the website

Open `index.html` in any text editor (VS Code, Notepad, TextEdit, etc.) and you can easily change:

- **Business name / tagline**
- **About text**
- **Services descriptions**
- **Contact email, phone, and location**
- **Portfolio images** — replace the Unsplash URLs with your own photos
- **Colors** — look for the Tailwind config near the top

### Replacing portfolio images
Replace the `src="https://images.unsplash.com/..."` links with links to your own images (or upload images into a folder called `images` and use relative paths like `images/my-painting-1.jpg`).

### Making the contact form work
The form currently shows a demo message. To receive real messages:

- Use **Formspree** (formspree.io) — free tier available
- Or **Netlify Forms** (if you host on Netlify) — just add `netlify` attribute to the form
- Or connect it to Google Forms / your email service
